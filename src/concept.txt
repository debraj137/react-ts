🧠 LESSON 1: What is Material UI (MUI)?
---------------------------------------------------
Material UI (MUI) is:
A React component library
Based on Google’s Material Design
Production-ready
Highly customizable

Instead of writing:
<button className="btn-primary">Submit</button>

You use:
<Button variant="contained">Submit</Button>


Much cleaner.

🧩 LESSON 3: Basic MUI Components
---------------------------------------------
🧪 Practice 1: Basic Button & Typography
📄 File: src/App.tsx
----------------------------------------------------------
import { Button, Typography } from "@mui/material";

function App() {
  return (
    <>
      <Typography variant="h4">
        Welcome
      </Typography>

      <Button variant="contained" color="primary">
        Click Me
      </Button>
    </>
  );
}

export default App;

Variants:
------------------
contained
outlined
text

🧩 LESSON 8: Design Consistency (Professional Thinking)
-------------------------------------------------------------------------
Design consistency means:
-------------------------------------
✔ Same spacing everywhere
✔ Same button styles
✔ Same border radius
✔ Same font scale

Good Practice
------------------------------------------
Don’t hardcode random colors
Use theme values
Create reusable UI components
Centralize design tokens

🧠 MUI vs Custom CSS vs Tailwind
Situation	Use
Enterprise app	MUI
Design system heavy	MUI
Utility-first styling	Tailwind
Full custom design	CSS + design system

📌 Interview line:
-------------------------------------------------------------------------
“I choose UI libraries based on project needs and scalability.”

🎯 INTERVIEW-READY SUMMARY
--------------------------------------------------------------------------------------------
“I use MUI for building scalable and accessible UI components. I customize components using the sx prop or styled API, centralize design using ThemeProvider, and ensure design consistency through a structured theme.”

🧠 LESSON 1: Authentication Basics (Very Important)
-----------------------------------------------------------
What is Authentication?
---------------------------------
Authentication = Who are you?
Examples: Email + Password, Google login, OTP, JWT token

Authentication vs Authorization
----------------------------------------
Term	Meaning
Authentication	Verify identity
Authorization	Verify permissions

Example:
Login success → authentication
Access admin page → authorization

📌 Interview line:
-------------------------------------------------------------------------------
“Authentication verifies identity, authorization verifies access rights.”
